# Sentrion

### Zero-Trust OS-to-Browser Exam Security Platform

Sentrion is a lightweight exam-proctoring platform that bridges the **operating system and browser** to provide stronger examination integrity without requiring administrator privileges.

## Features

* 🔐 OS-to-Browser Security Bridge
* 🧠 On-device AI Proctoring
* 👁️ Face, Gaze & Blink Detection
* 👥 Multi-Person Detection
* 🛡️ Anti-VM & Virtual Camera Detection
* ⚙️ Real-Time Process Monitoring
* 🖥️ Display & Overlay Detection
* 🔑 Single-Use Exam Passcodes
* 📸 Event-Based Forensic Evidence
* 📊 Graduated Integrity Scoring
* 🚫 No Continuous Video Streaming

## Tech Stack

**Frontend:** HTML, CSS, JavaScript, MediaPipe, WebAssembly
**Native Companion:** Python, Windows WMI, Win32 APIs
**Backend:** Node.js, WebSocket
**Security:** HMAC-SHA256, SHA-256

## Platform

* Windows 10 / 11 (64-bit)
* Modern browsers
* No administrator privileges required

## Project Status

**Core system ~80% complete**

Sentrion is designed for **university examinations, recruitment assessments, technical interviews, and other high-stakes online assessments**.
